# Tata Tertib & Panduan RuangKita

Selamat datang di dokumentasi resmi **RuangKita** — platform peminjaman ruangan dan pelacakan izin kegiatan organisasi mahasiswa Universitas Brawijaya.

Semua proses dilakukan secara daring. Tidak perlu lagi mengunjungi beberapa kantor hanya untuk memeriksa status tanda tangan berkas.

## 4 Langkah Mudah Peminjaman Ruangan

### 1. Cek Ketersediaan Ruangan
Buka menu **Kalender Live** di aplikasi RuangKita dan pilih slot tanggal serta jam yang belum terisi agar tidak bentrok dengan jadwal kegiatan lain.

### 2. Isi Formulir Digital
Lengkapi seluruh informasi pengajuan secara akurat:
- Nama kegiatan dan organisasi mahasiswa (Ormawa)
- Penanggung jawab (PIC) beserta nomor kontak aktif
- Ruangan, tanggal, jam mulai, dan jam selesai
- Perkiraan jumlah peserta dan kebutuhan fasilitas

### 3. Unggah Dokumen Pendukung
Lampirkan berkas **Proposal Kegiatan** dan **Surat Permohonan Ruangan** dalam format PDF yang terbaca jelas.

### 4. Pantau Persetujuan Secara Real-Time
Pantau progres verifikasi berkas dari tahap Admin hingga persetujuan akhir **Wakil Dekan III** di menu **Peminjaman & Izin**. Setelah disetujui, surat izin resmi dapat langsung diunduh.
