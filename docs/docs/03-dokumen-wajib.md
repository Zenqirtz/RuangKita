# Dokumen Wajib & Persyaratan Berkas

Pastikan seluruh dokumen diunggah dalam format **PDF** dengan ukuran yang wajar dan tulisan yang terbaca jelas.

| Nama Dokumen | Keterangan | Status |
| :--- | :--- | :---: |
| **Proposal Kegiatan** | Memuat latar belakang, tujuan, susunan acara (*rundown*), dan daftar kebutuhan fasilitas. | **Wajib** |
| **Surat Permohonan Ruangan** | Surat resmi yang telah ditandatangani oleh Ketua Ormawa dan Dosen Pembimbing / Pembina. | **Wajib** |
| **Rundown Kegiatan Detail** | Rincian waktu dan penanggung jawab untuk setiap sesi acara. | Kondisional |
| **Surat Izin Keramaian** | Diperlukan khusus untuk kegiatan dengan jumlah peserta di atas **100 orang**. | Kondisional |

## Tampilan Pengunggahan Berkas

Dokumen diunggah langsung pada halaman **Pengajuan Baru** sebelum menekan tombol kirim pengajuan.

![Halaman Unggah Dokumen Peminjaman](/img/screenshots/booking-create.png)

:::tip Tips Verifikasi Cepat
Pastikan tanda tangan dan stempel pada Surat Permohonan sudah lengkap sebelum diunggah agar berkas tidak dikembalikan dengan status **Perlu Revisi**.
:::
